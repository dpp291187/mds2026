# Baseline provenance

The two Rust snapshots are the pinned Plonky3 v0.4.0 sources used to check the baseline kernels and the KoalaBear modulus. Source URLs and SHA-256 digests appear in `source_manifest.json`; the upstream MIT and Apache-2.0 license texts accompany them.

`poseidon2_composition_source.json` records the separately inspected HorizenLabs generator, its pinned commit and hash, and the distinction between the reference width-four layer and the Plonky3 wrapper. The complete HorizenLabs source is not redistributed. These provenance records do not constitute a new license grant for the original project.
